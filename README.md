# Embassy of India, Brazzaville: homepage, sample 4

Static homepage in the layout of the Tel Aviv mission site, using the Brazzaville content.
It follows DBIM 3.0 (Blue colour group, Noto Sans, functional Coral Red for emergencies) and WCAG 2.2 AA.

- index.html: markup
- assets/css/style.css: styles; colour and type settings are at the top
- assets/js/main.js: sticky header, accessibility and search menus, navigation, hero slider, tabs
- assets/images/: emblem, photos, event images

Open index.html in a browser. Fonts load from Google Fonts.
Confirm that the photo captions match the events they show.
